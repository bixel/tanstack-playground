# Stack Showcase

A minimal, client-only starter for learning **React 19 · TanStack Router · TanStack Query · TanStack Table · shadcn/ui · Tailwind v4**, with an in-browser fake backend.

```bash
npm install
npm run dev      # http://localhost:5173
```

`src/routeTree.gen.ts` is generated by the router plugin the first time `npm run dev` (or `npm run build`) runs. Until then your editor will complain about the import in `main.tsx` — that's expected.

## What's where

| Path | Layer | Try this |
|---|---|---|
| `src/routes/` | **TanStack Router** (file-based) | Add `src/routes/about.tsx` → the route exists, and `<Link to="/about">` is type-checked |
| `src/routes/table.tsx` | Router loader + typed search params + **TanStack Table** | Sort/search, then reload — state comes back from the URL |
| `src/queries/` | **TanStack Query** (`queryOptions`, mutations, optimistic updates) | Toggle *Flaky network* and watch rollbacks |
| `src/api/` | In-client "backend" (localStorage + latency + failures) | Replace a function body with `fetch()` |
| `src/components/ui/` | **shadcn/ui** components (you own the code) | `npx shadcn@latest add dialog` |
| `src/index.css` | Tailwind v4 + shadcn theme tokens | Change `--primary` and everything follows |

## Two data-loading patterns, side by side

- **`/query`** — no loader. `useQuery` in the component, render `isPending` / `isError` states yourself.
- **`/table`** — `loader: ensureQueryData(...)`, then `useSuspenseQuery` in the component. Data is ready before render; hovering the nav link prefetches it.

Pick per page. Both share the same cache, keyed by `queryOptions`.

## Devtools

Query devtools (bottom-left) and Router devtools (bottom-right) appear in dev only.

## Deployment

Every push to `master` builds the app and publishes `dist/` to GitHub Pages via `.github/workflows/deploy-pages.yml` (repo root). The workflow sets `BASE_PATH=/<repo>/`, which Vite uses as `base` and the router as `basepath`; `index.html` is copied to `404.html` so deep links like `/table` work.

One-time setup: **Settings → Pages → Source: GitHub Actions**.
